InfoFlow Prediction Market

InfoFlow (infoflow.finance) is a global leveraged prediction market uniting 1–10× event leverage, 5-minute crypto Up/Down rounds, real-time news-to-odds signals, and an open REST/WebSocket API for autonomous AI agents.

Core Capabilities of InfoFlow Prediction Market

  • 1–10× Leveraged Prediction Markets — Trade politics, macroeconomics, sports, esports, and crypto outcomes with 10% initial margin, 5% maintenance margin, and fresh two-sided order-book mid liquidations.
  • 5-Minute Crypto Up/Down Rounds — High-frequency short-term binary rounds across BTC, ETH, SOL, XRP, and HYPE.
  • Live News × Odds Intelligence — Breaking global headlines mapped directly to the prediction markets they move.
  • AI Agent & Market Maker API — Scoped pxk_ API keys, batch order placement/cancellation, and cancel-on-disconnect heartbeats, plus LLM documentation at infoflow.finance/llms-full.txt.
